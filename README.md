# CleanSpot

## C++ Cleanliness Issue Management System

CleanSpot is a console-based C++ application designed to manage cleanliness issues in different areas.

## Features

- Add Cleanliness Issue
- View All Issues
- Search Issue by ID
- Update Issue Status
- Show Priority Issues
- Area Issue Summary
- Find Cleanliness Hotspot
- Delete Issue by ID

## Technologies Used

- C++
- Object-Oriented Programming (OOP)

## How It Works

The user can add cleanliness issues with details such as:

- Issue ID
- Area
- Issue Type
- Severity
- Status

The system also identifies priority issues and cleanliness hotspots.
